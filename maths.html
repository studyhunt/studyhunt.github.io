Important formulas ko topic-wise revise karo.

Algebra

Quadratic Equations

ax² + bx + c = 0
D = b² − 4ac
x = (−b ± √D) / 2a

D > 0: two real roots
D = 0: equal roots
D < 0: no real roots

Algebra

Sequences & Series

aₙ = a + (n−1)d
Sₙ = n/2 [2a + (n−1)d]
GP: aₙ = arⁿ⁻¹
Sₙ = a(rⁿ−1)/(r−1)
Trigonometry

Basic Identities

sin²θ + cos²θ = 1
1 + tan²θ = sec²θ
1 + cot²θ = cosec²θ
Trigonometry

Compound Angles

sin(A+B) = sinA cosB + cosA sinB
cos(A+B) = cosA cosB − sinA sinB
tan(A+B) = (tanA+tanB)/(1−tanA tanB)
Coordinate Geometry

Straight Lines

y = mx + c
m = (y₂−y₁)/(x₂−x₁)
Distance = |ax₁+by₁+c| / √(a²+b²)
Coordinate Geometry

Circle

(x−h)² + (y−k)² = r²
Centre = (h,k)
Radius = r
Calculus

Differentiation

d(xⁿ)/dx = nxⁿ⁻¹
d(sin x)/dx = cos x
d(cos x)/dx = −sin x
d(eˣ)/dx = eˣ
Calculus

Basic Integration

∫xⁿ dx = xⁿ⁺¹/(n+1) + C
∫1/x dx = ln|x| + C
∫eˣ dx = eˣ + C
Algebra

Matrices

A⁻¹ = adj(A)/|A|
AA⁻¹ = I

A⁻¹ exists when |A| ≠ 0.

Probability

Basic Probability

P(A) = n(A)/n(S)
P(A') = 1 − P(A)
0 ≤ P(A) ≤ 1
Vector & 3D

Vectors

|a| = √(a₁²+a₂²+a₃²)
a·b = |a||b|cosθ
a·b = a₁b₁+a₂b₂+a₃b₃

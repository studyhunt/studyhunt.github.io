📚 Class 11 Mathematics

Sets

A ∪ B = Union
A ∩ B = Intersection
n(A ∪ B) = n(A)+n(B)-n(A ∩ B)

Quadratic Equations

ax² + bx + c = 0
D = b² − 4ac
x = (−b ± √D)/2a

Sequence & Series

aₙ = a + (n−1)d
Sₙ = n/2 [2a + (n−1)d]

Trigonometry

sin²θ + cos²θ = 1
1 + tan²θ = sec²θ
1 + cot²θ = cosec²θ

Straight Lines

y = mx + c
m = (y₂−y₁)/(x₂−x₁)
Distance = |ax₁+by₁+c|/√(a²+b²)

Circles

(x−h)² + (y−k)² = r²
Centre = (h,k)
Radius = r

📚 Class 12 Mathematics

Limits

lim sin x/x = 1
lim (eˣ−1)/x = 1

Differentiation

d(xⁿ)/dx = nxⁿ⁻¹
d(sin x)/dx = cos x
d(cos x)/dx = −sin x

Matrices

|A| = Determinant of A
A⁻¹ = adj(A)/|A|

Probability

P(A) = n(A)/n(S)
P(A') = 1 − P(A)

Vectors

|a| = √(a₁²+a₂²+a₃²)
a·b = |a||b|cosθ

3D Geometry

Distance = √[(x₂−x₁)²+(y₂−y₁)²+(z₂−z₁)²]
